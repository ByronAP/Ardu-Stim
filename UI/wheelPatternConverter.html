About Run-Length Encoding (RLE)

Run-Length Encoding is a simple compression technique that replaces repeated values with a value and a count of repetitions.

RLE Format

The RLE format used looks for repeating patterns and encodes them as:

pattern_length, [pattern values], repeat_count, [more patterns]...

For example, if the pattern "1,0" repeats 10 times, it would be encoded as:

2, 1,0, 10, [rest of the data]

Handling Long Repeats

Since the ArduStim uses unsigned chars (bytes) with values 0-255, any run length greater than 255 is automatically split into multiple chunks:

// Example: 300 repetitions of pattern "1,0" RLE: 2, 1,0, 255, 2, 1,0, 45

Memory Savings

The RLE format typically reduces the wheel pattern size by 50-80% depending on the pattern complexity. The optimized format can achieve even better compression for highly repetitive patterns.
